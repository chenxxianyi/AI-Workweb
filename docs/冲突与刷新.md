# 冲突与刷新

活跃页面每30秒重校验查询，切回页面重校验；后台不轮询，失败按60/120/240/300秒上限退避，查询内部网络重试另有短退避。组件输入保存在本地状态，查询刷新不能替换输入。

知识与项目编辑固定打开时的version。412展示服务器字段及本地仍在输入框的字段；使用服务器内容可放弃本地，或人工修改后明确采用服务器新版本保存。服务器再次变化仍返回412。台账编辑固定选中记录，冲突可查看最新记录并采用新版本人工合并。任务状态离线冲突在本机队列读取服务器状态与版本后明确重新确认；创建新意图后才允许同步。未知结果仍使用原键查询，不能当成已失败生成新意图。

有输入的知识、项目、台账、今日任务、日志、离线编辑器阻止应用壳更新和离线重新加载，并注册浏览器退出提示。应用内导航后可从知识本机草稿恢复；普通表单仍应先保存或导出。
