# 使用手册

## 登录和空间

使用正式地址 http://127.0.0.1:3000。公开注册关闭，Owner初始账号由本机管理员初始化。忘记密码由管理员签发一次性恢复凭据；不要把恢复链接发送到公开渠道。登录过期时在当前页重新验证同一账号，表单输入保留。

Owner管理空间、成员、邀请、导入与维护；Editor编辑业务并导出；Viewer只读，可以复制内容，不能创建或修改业务。服务器逐次鉴权，前端隐藏按钮不代替权限检查。切换空间、账号或退出前，先处理本机未同步资料；界面会提示草稿与待处理数量。

## 四个模块

**今日聚焦**按当前空间业务日显示紧急、今日及昨日未完成任务。优先级P0/P1/P2，状态待做/进行中/完成。昨日顺延需要预览确认，不自动修改更早逾期或已完成任务。开发日志可按日记录，中文输入法确认候选不会触发快捷保存。

**项目雷达**保存项目阶段、技术栈、仓库和一个明确“下一步”。无任务的自动进度为0%；手动0%同样有效。详情聚合本项目任务、知识和台账。归档与删除是不同动作。创建结果未知时，页面保存原内容和幂等键，只能用原提交确认；超过7天需导出并人工核对，不能换新键盲目重发。核对完毕后可在“本机草稿与待同步”中删除对应project-create-pending记录，再回到项目页。

**知识库**包含笔记/设计/ADR/排错/命令，状态为草稿/已验证/已归档。草稿可先记一半；转已验证前补齐标题、摘要和正文。正文上限20480个UTF-8字节，中文会占多个字节。Markdown不执行原始HTML；代码原文可复制。成功复制才记录使用次数，失败不会计数。正文保留最近5条修订，恢复前也会保留当前正文。

**AI台账**记录日期、工具、场景、投入、节省和效果。投入为1～1440分钟，节省0～1440分钟，效果1～5整数；省略节省时按投入处理。可关联项目和知识；月度图表与近8周趋势和数字结论来自真实数据。零记录与零节省不代表错误。

## 快捷键和冲突

- N：快速捕获；输入框、编辑器、中文输入过程中不触发。
- Ctrl/Cmd+K：全局搜索；中文、英文和短词按当前空间查询。
- Ctrl/Cmd+Enter：确认当前快速捕获；Esc关闭后输入保留。
- 键盘Tab在对话框内循环，Esc关闭并还原焦点。

遇到412版本冲突，先查看服务器最新内容，再手动合并或另存草稿，不直接覆盖。表单编辑开始时固定原版本；后台刷新不会偷换为新版本。任务沉淀会关联知识，重复请求不会重复创建。

## 离线与本机资料

应用壳只缓存公开静态构建。最近50个允许的业务视图可作7天内只读参考，账号和空间分开；离线身份仅用于本机只读，不能替代服务器授权。

待同步只支持开发日志、知识草稿和任务状态变更。项目、已验证知识编辑、成员、导入和维护不能离线排队。操作需要联网重新核验账号、角色、空间版本和任务原版本，再手动同步；超时保留原键，冲突需明确重选。超期或权限失效的记录可导出，不能自动强制提交。

浏览器存储配额不足时按提示导出本机资料。退出会清除当前账号私有缓存，先确认未同步内容。服务worker有新版本时先保存表单，再选择更新应用；不要在有未保存资料时强行刷新。

## 传输、回收和备份

导出JSON包含业务字段、关联、修订和使用统计，不包含密码、会话或邀请。Markdown导出用于阅读。任务完成后从受控链接下载，过期后重新导出。

导入先预览，核对实体数量、断链与冲突，再确认。旧schema1文件需要来源标识；同一来源重复导入沿用映射。来源字段不能赋予权限。正在提交时不能把“取消任务”当作撤销；使用导入恢复记录与明确的冲突选择。

普通删除进入回收站，可由Owner恢复；彻底删除和空间清空有额外确认。正式库回收站中保留了明确命名的发布技术验收记录，正常列表为空。这些记录不会冒充用户真实业务。

业务导出与数据库备份分开。设置显示备份最近状态；完整数据库恢复由本机管理员按运维手册执行。当前备份仅在本机，不能承受整盘损坏，异机灾备是后续扩展。
