## 1. 信息架构与路由

一级导航四模块 + 设置；URL 承载筛选，可分享、可前进后退。所有路由在未登录时重定向 `/login?next=<原路径>`。

| 路由 | 页面 | 关键查询参数 | 说明 |
|---|---|---|---|
| `/login` | 登录 | `next` | 公开注册关闭；失败统一文案 |
| `/invite/:token` | 接受邀请 | — | 一次性令牌，过期／已用有明确失败态 |
| `/today` | 今日聚焦 | `date`、`group`、`priority` | 默认业务日＝空间时区今日 |
| `/today/logs` | 日志时间线 | `before`、`author` | 分页游标 |
| `/projects` | 项目雷达 | `status`、`q`、`tag` | 卡片网格 |
| `/projects/:id` | 项目详情 | `tab`（tasks／knowledge／ledger） | 三块数据分页 |
| `/kb` | 知识库 | `q`、`type`、`status`、`tag`、`sort`、`page` | 组合筛选全部写入 URL |
| `/kb/:id` | 知识详情／编辑 | `mode=edit\|preview\|revisions` | 默认只读详情 |
| `/kb/new` | 快速捕获（整页兜底） | `from=task:<id>`、`projectId` | 浮层失败时降级为整页 |
| `/ledger` | AI 台账 | `month`、`tool`、`scene`、`projectId` | 月份切换保留筛选 |
| `/settings` | 设置 | `tab=preferences\|workspace\|members\|trash\|data\|security` | 六个分区 |
| `/search` | 全局搜索（浮层） | `q`、`scope` | Ctrl/Cmd+K 打开，Esc 关闭 |
| `*` | 404 | — | 提供“回到今日” |

## 2. 页面结构与交互要点

### 2.1 登录 / 邀请 / 会话
- 登录表单：账号、密码、登录按钮；无“注册”入口。错误提示统一为“账号或密码不正确”，连续失败按服务端限流提示剩余等待时间。
- 邀请：校验令牌 → 展示将加入的空间与角色 → 设置密码 → 进入空间。令牌失效时给出“请 Owner 重新生成邀请”，不提供自助重发。
- 会话过期（401）：保留当前输入与路由，弹出可关闭的登录对话框，登录成功后回到原路由与原筛选。
- 无权限（403）：页面级显示原因与联系人；操作级按钮禁用但**保留可见**，附 `title` 说明，避免用户猜测入口消失的原因。

### 2.2 今日聚焦
- 顶部摘要条：业务日、紧急项计数、昨日未完成计数、批量顺延入口。
- 紧急区置顶：逾期>0 天（红点）、doing 停滞>3 天（橙点）、draft 创建>7 天（灰点＋“草稿超期”）。完成或改期后立即移出并按新条件重算。
- 任务项：优先级 P0/P1/P2、标题、项目、截止日、状态；行内动作：完成、改期、撤销（隐藏 5 秒内的撤销条，不阻塞其他操作）。
- 分组 Tab：今日任务／昨天未完成／全部。批量顺延只在“昨天未完成”出现，先预览后确认，确认弹窗列出逐条目标日期。
- 日志输入：`Enter` 保存、`Shift+Enter` 换行、`Esc` 清空确认；输入法 `isComposing` 期间一律不提交。
- 空态：无今日任务时显示“今天还没有任务 + 新建任务”；筛选无结果显示“没有符合筛选的任务，清除筛选”。

### 2.3 项目雷达 / 项目详情
- 卡片：名称、阶段、技术栈、进度（自动／手动标签）、唯一“下一步”单行、无活动 ≥7 天提醒、归档标记。进度为手动时即使 0% 也显示 0%，不被自动值覆盖。
- 筛选：进行中／7 天无活动／已归档，写入 URL。
- 详情三块：关联任务、关联知识、关联台账，各自分页且只显示本项目；每块有“新建并预选本项目”的入口。
- 编辑：名称、阶段、技术栈、下一步、进度模式（自动／手动）、手动进度值；保存走 If-Match，冲突返回 412 时展示对比。

### 2.4 知识库
- 列表行：标题、类型徽标、状态徽标、标签、摘要、最近访问、复制次数；草稿超期与 30 天未访问在“整理”入口聚合展示。
- 筛选：类型（五类）、状态（三态）、标签多选、排序（最近更新／最近访问／复制次数）；全部写入 URL。
- 详情：标题、摘要、正文（Markdown 渲染，白名单）、标签、项目关联、修订入口、复制入口、使用统计。
- 编辑：摘要（verified 必填）、正文（≤20480 字节，实时剩余字节）、标签、类型、状态；`verified` 缺标题／摘要／正文时就地报错不提交。
- 快速捕获：浮层（标题、正文、类型、项目、标签），`N` 打开、`Ctrl/Cmd+Enter` 保存、`Esc` 关闭并保留草稿；正文自动聚焦；浮层不可用时跳 `/kb/new` 整页。
- 复制：主路径 `navigator.clipboard.writeText`；失败降级为“选中全文 + 提示手动复制”，**失败不计数**；成功后再次点击不重复计数（同一会话按钮进入已复制态）。

### 2.5 AI 台账
- 表单：日期（默认业务日）、工具、场景、分钟数、节省分钟、效果 1–5（分档控件）、关联项目／任务、备注。
- 校验：minutes>0、saved≥0、effect 为 1–5 整数；非法值就地提示，不提交。
- 列表与统计同屏：月份切换（保留筛选）、条数、平均效果、累计节省；两张 SVG 图（按场景条形、近八周折线）；空月份显示文字结论而非空图。

### 2.6 设置
- 个人偏好：主题（跟随系统／浅色／深色，首屏前应用，避免闪白）、默认落地页、列表密度。
- 空间：名称、时区（仅 Owner；修改需二次确认并审计，提示“今日与逾期口径将改变”）。
- 成员：列表、角色变更、移除、生成邀请链接（一次性、24 小时、仅存哈希、可复制）。
- 回收站：条目、剩余天数、恢复、彻底删除（Owner，二次确认 + 审计）。
- 导入导出：导出 JSON／Markdown 为后台 job（进度、过期下载链接）；导入三步（选择文件 → 预览与冲突决策 → 确认提交），预览不写业务数据。
- 会话与安全：会话列表、当前会话标记、吊销；修改密码后吊销其他会话。

### 2.7 全局搜索
- Ctrl/Cmd+K 任意页打开浮层；输入即查（防抖 250ms）；结果分组（任务／知识／项目），键盘 ↑↓ 选择、Enter 打开、Esc 关闭并恢复焦点。
- 结果条目显示命中字段（标题／标签／摘要／正文）；两字中文词走短词路径，并在开发模式显示耗时用于性能回归。
- 不相关热门条目不得因为“热门”进入结果；排序以字面命中优先，其次更新时间。

## 3. 关键流程

### 3.1 任务 → 沉淀 → 知识 → 复制 → 台账（主闭环）
1. 今日聚焦某任务卡片 → “沉淀知识”。
2. 浮层以任务标题预填标题、`from=task:<id>`，光标聚焦正文首行；可改类型、标签、项目（默认带入任务所属项目）。
3. 保存：服务端在同一事务创建知识条目与任务关联；成功后返回原任务卡片，并显示“已关联知识”标记。
4. 打开知识详情 → 复制正文：成功计数 +1 并提示“已复制”；失败提示手动复制且不计数。
5. 从知识详情 → “记一条台账”：带入项目与任务关联，保存后回到知识详情。
6. 任意环节取消：返回上一层原位置（列表滚动位置与筛选保持）。

### 3.2 导入（schema1 / schema2）
选择文件 → 上传校验（格式、版本、字段、引用）→ 预览报告（新增／更新／冲突／忽略，可逐项决策）→ 确认生成 planHash → 后台 job 应用 → 结果报告（成功条数、失败原因、可下载错误清单）。
- 预览不修改业务数据；planHash 过期（默认 30 分钟）后必须重新预览；同一导入请求重放不重复写入。

### 3.3 并发冲突
- 编辑页持有 `version`；保存提交 `If-Match`。412 时打开对比面板（左：我的内容，右：服务器内容），提供“以服务器为准”“保留我的（另存为新修订／重新提交）”“合并后保存”三种出口；不静默覆盖。
- 428（缺 If-Match）：提示页面已过期，刷新后重试。

### 3.4 离线与弱网
- 离线：顶部状态条“离线 · 只读缓存”；已缓存页面可读；仅新建日志、新建知识草稿、修改任务状态允许写入本地队列，显示“待同步 N 条”，**不得显示“已保存”**。
- 恢复联网：按原幂等键提交；成功→“已同步”；冲突→进入对比面板；服务端拒绝（403／410）→ 提示并保留本地副本供导出。
- 账号／空间切换：队列与缓存按 `userId + workspaceId` 分区；未同步内容不可被其他账号读取，退出时提示先导出。

## 5. 键盘与输入法

- 全局：`Ctrl/Cmd+K` 搜索；`N` 快速捕获（输入框／富文本内不触发）；`Esc` 关闭浮层并恢复焦点；`?` 显示快捷键帮助。
- 列表：`↑↓` 移动、`Enter` 打开、`Space` 勾选、`Esc` 取消选择。
- 表单：`Enter` 在单行输入提交，多行文本内为换行；`Tab` 顺序与视觉顺序一致；错误提示用 `aria-describedby` 关联。
- 输入法：组合输入期间（`compositionstart` 到 `compositionend`）不响应 `Enter`、`N`、`↑↓` 等快捷键。

## 6. 移动（375px）与响应式

- <768px：底部标签栏（今日／项目／知识／台账／设置）+ 顶部空间切换；单列；不出现横向滚动。
- 768–1023px：两列，导航折叠为图标 + 抽屉。
- ≥1024px：左侧导航 216px + 主区最大 1180px。
- 触控：点击区 ≥44×44px；输入字号 ≥16px（防 iOS 聚焦缩放）；浮动捕获按钮避开底部标签栏。
- 移动专用：任务卡片左滑完成／改期；日志输入框随键盘上移。

## 7. 设计决策（F03 转写为 ADR）

| 编号 | 决策 | 理由 |
|---|---|---|
| D-01 | 不引入组件库与图标包，使用 CSS 变量 + 内联 SVG 图标 | 私有部署、离线优先、包体与许可可控；避免公共 CDN |
| D-02 | 字体使用系统字体栈（含中文回退） | 离线可用、无字形下载延迟；不加载远程字体 |
| D-03 | 强调色单一（青绿），紧急度用语义色而非多种品牌色 | 信息密度高时减少视觉噪音；颜色不作为唯一指示（配合文字／图标） |
| D-04 | 主题在首屏前由服务端偏好 + 本地缓存决定 | 避免闪白；偏好跨设备一致 |
| D-05 | 筛选状态一律进 URL | 可分享、可后退、刷新不丢 |
| D-06 | 危险操作统一“二次确认 + 审计” | 满足 R22／R21；避免误删 |
| D-07 | 保存状态只用三值：已保存／待同步／保存失败（含结果未知） | 呼应 R23／R24，禁止把待同步写成已保存 |
