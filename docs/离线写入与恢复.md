# 离线写入与恢复

入口：侧栏“本机草稿与待同步”（/offline）。首次联网进入后记录空间版本、业务日和是否可写；断网时仍可把新日志、新知识草稿、任务状态排入本机 IndexedDB。任务状态须提供详情中的任务 ID 与原版本，联网后按原版本提交。已有正文不会自动覆盖服务器，只保留本地草稿供对比合并。

每项有账号、空间、本地操作 ID、固定幂等键、创建时间、原版本及载荷。“待同步”不表示已保存到服务器。点击核验身份并同步：先核验 /auth/me、成员权限，再查原幂等结果；已完成的直接移除，否则用原键提交。后端同一事务锁空间及成员、校验版本、写业务与幂等结果。切换账号竞态亦由载荷 userId 检查拒绝。

超过7天不会重放；冲突或权限错误保留本地意图。配额不足时保留输入，可导出当前输入，恢复存储后重试。刷新后队列仍在；浏览器清除站点数据会删除本机草稿，须主动导出。退出或切换账号时，有未同步资料会明确提示：取消先导出，或确认删除后退出。服务器返回不确定时不要复制创建新项，应重试原项。

API：GET /workspaces/:id/offline-operations/context；GET /:key 查询当前用户当前空间原操作；POST 根路径仅接受三种白名单操作。写入须带 CSRF 与 Idempotency-Key，载荷包含 userId、workspaceVersion、createdAt、operation。知识创建强制 draft；任务采用 payload.version CAS；任何正文修改不在离线重放白名单内。

验收：FS036 真实 PostgreSQL 12项检查，前端持久化/网络/过期/配额与退出测试；浏览器实际停止 API 3001、断网排队、刷新仍待同步、恢复 API 后原键提交并在今日日志显示一条。截图位于 FS036。Safari、异机灾备按 ADR-0009 后续扩展。
