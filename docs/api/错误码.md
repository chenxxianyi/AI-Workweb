# 错误码与状态码

> 版本：V1.0（F03 冻结）｜日期：2026-11-03｜配套：[OpenAPI 草案](openapi.yaml)、[数据库与接口设计](../../全栈开发任务/数据库与接口设计.md) 第 4 节
> 规则：HTTP 状态表达**类别**，`error.code` 表达**具体原因**；两者组合稳定，前端按 `code` 分支，不按文案匹配。

## 1. 响应封装

```jsonc
// 成功
{ "data": { }, "meta": { "nextCursor": "…", "hasMore": false }, "requestId": "r-8f2c9a" }
// 失败
{ "error": { "code": "VALIDATION_FAILED", "message": "标题不能为空", "fieldErrors": { "title": ["不能为空"] } },
  "requestId": "r-8f2c9a" }
```

- `requestId` 同时写入响应头 `X-Request-Id`、日志与审计，供用户报错时对齐。
- `message` 面向用户，中文，不含堆栈、SQL、内部路径、token。
- 不返回堆栈；`5xx` 仅返回通用文案 + `requestId`。

## 2. 错误码表

| code | HTTP | 含义 | 触发条件 | 前端处理 |
|---|---|---|---|---|
| `VALIDATION_FAILED` | 422 | 字段校验失败 | DTO 校验不通过、枚举非法、长度／字节超限 | 就地标红 `fieldErrors` |
| `MALFORMED_REQUEST` | 400 | 请求语法错误 | JSON 解析失败、查询参数类型错误 | 提示刷新页面 |
| `UNAUTHENTICATED` | 401 | 未登录 | 无会话 cookie、会话不存在 | 登录对话框，保留输入 |
| `SESSION_EXPIRED` | 401 | 会话过期或被吊销 | `idle_expires_at`／`absolute_expires_at` 已过、`revoked_at` 非空 | 登录对话框，登录后回原路由 |
| `AUTH_INVALID_CREDENTIALS` | 401 | 账号或密码不正确 | 登录失败（不区分账号是否存在） | 统一文案 |
| `CSRF_INVALID` | 403 | CSRF／来源校验失败 | 缺 `X-CSRF-Token`、token 不匹配、Origin 不在允许列表 | 重新取 CSRF token 后重试一次 |
| `FORBIDDEN` | 403 | 角色无权 | 已确认成员但角色不足 | 显示原因与 Owner 联系人 |
| `NOT_FOUND` | 404 | 对象不存在或不属于可访问空间 | 含跨空间访问（防探测） | 回到列表并提示 |
| `CONFLICT` | 409 | 业务冲突 | 唯一约束冲突（如标签重名、最后 Owner） | 提示具体冲突项 |
| `IDEMPOTENCY_KEY_REUSED` | 409 | 幂等键与请求体不一致 | 同 key 不同 body | 提示“请求已变更”，禁止静默重试 |
| `PLAN_STALE` | 409 | 导入计划过期或触及实体已变 | `plan_hash` 不符、`base_versions` 变化、超过 24 小时 | 重新预览 |
| `PRECONDITION_FAILED` | 412 | 版本冲突 | `If-Match` 与当前 `version` 不符 | 打开对比面板（三出口） |
| `PAYLOAD_TOO_LARGE` | 413 | 请求或文件超限 | JSON >128KiB、导入文件 >512MiB 或 >25 万条 | 提示上限，不截断 |
| `PRECONDITION_REQUIRED` | 428 | 缺少 `If-Match` | 条件写接口未带版本 | 刷新实体后重试 |
| `RATE_LIMITED` | 429 | 限流 | 登录、搜索、导出等超过阈值 | 显示剩余等待时间 |
| `BODY_LIMIT_UNSUPPORTED` | 413 | 正文超过 20480 字节 | 知识正文 UTF-8 字节超限 | 显示剩余字节数 |
| `LAST_OWNER_PROTECTED` | 409 | 最后一位 Owner 保护 | 移除／降级唯一 Owner | 提示先转移所有权 |
| `ENTRY_STATE_INVALID` | 422 | 知识状态不满足要求 | `verified` 缺标题／摘要／正文 | 就地提示缺项 |
| `REVISION_NOT_FOUND` | 404 | 修订不存在 | 修订已裁剪或不属于该条目 | 刷新修订列表 |
| `IMPORT_VERSION_UNSUPPORTED` | 422 | 导入文件版本不支持 | `schema`／`schemaVersion` 未知或过高 | 提示可支持的版本 |
| `IMPORT_REFERENCE_MISSING` | 422 | 导入引用断链 | 关联的项目／任务／条目不在同空间 | 在预览中列为“拒绝／断链” |
| `TRANSFER_STATE_INVALID` | 409 | 作业状态不允许该操作 | 已提交任务取消、重复 commit | 刷新作业状态 |
| `DOWNLOAD_FORBIDDEN` | 403 | 下载归属校验失败 | job 不属于当前用户／空间 | 提示无权限 |
| `CLEAR_CONFIRMATION_REQUIRED` | 422 | 清空空间缺少确认 | 未提交空间名或未重新认证 | 引导二次确认 |
| `UNSUPPORTED_MEDIA_TYPE` | 415 | 内容类型不支持 | 非 `application/json`／`multipart/form-data` | 提示正确格式 |
| `INTERNAL_ERROR` | 500 | 未预期错误 | 未捕获异常 | 显示 requestId，引导重试 |
| `SERVICE_UNAVAILABLE` | 503 | 数据库或依赖暂不可用 | 连接池耗尽、迁移未就绪 | 写入结果未知 → 用同键查询状态 |
| `MAINTENANCE` | 503 | 维护中 | 配置开关开启 | 显示维护窗口说明 |

## 3. 状态码使用约束

1. 401 与 403 严格区分：未认证 → 401；已认证但无权 → 403。
2. 跨空间访问统一 404，避免通过 403／404 差异探测其他空间对象。
3. 条件写冲突一律 412，并在响应体 `data.currentVersion` 返回可授权查看的版本；不返回对方未提交内容。
4. 幂等键重复但请求体相同 → 直接返回首次结果（200／201），不报错。
5. 任何 5xx 必须带 `requestId`，且日志中有对应记录；不允许“静默成功”。
6. 校验错误必须给 `fieldErrors`（字段路径用 DTO 名，不用数据库列名）。
