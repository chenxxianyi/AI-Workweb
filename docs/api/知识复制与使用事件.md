# 知识复制与使用事件（F24）

GET /api/v1/workspaces/{workspaceId}/entries/{entryId}/usage 返回data.useCount与lastUsedAt，无读取副作用。
POST同路径，所有空间成员可提交；需要CSRF和Idempotency-Key，body严格为空对象。未知字段422；缺key422；跨空间／已删除条目404；未登录401。
成功返回useCount、lastUsedAt、replayed；同key重试／并发只计一次。独立usage表，不改变正文version、updatedAt或项目开发活动时间。浏览器复制成功后才发送，服务器不能证明系统剪贴板事实。
统计失败UI明确区分“已复制／未保存统计”，重试不再次复制并复用原key。
