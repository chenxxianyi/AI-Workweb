# 知识搜索接口（F22，C-24）

根路径 /api/v1/workspaces/{workspaceId}/search，cookie会话与空间守卫强制生效。

- GET /entries：q必填1～100字符；status/type/projectId/tag可筛选；limit整数1～100默认20；cursor限当前空间／条件／页大小，15分钟内有效。
- 响应data：{hits:[{id,title,summary,type,status,tags,score,updatedAt}],hasMore,nextCursor,tookMs}。
- GET /related/{entryId}：共享标签数量降序，排除自身／已删除／其他空间，最多3条。
- GET /organize：{top,overdueDrafts,staleEntries}；Top5按使用量和最后使用时间；超期草稿>7天、久未访问>=30天，以空间日期为准。
- 422：非法参数；400：游标损坏／过期／条件改变；401：未登录；404：无权限空间／对象；429：超过搜索限流。

排名：标题精确100、前缀80、包含60、标签40、摘要20、正文10；仅文本命中可参与，加近期使用、有限使用量和近期编辑；已归档整体减半；再按updatedAt、id降序。分页固定评分参考时刻，避免随请求时间漂移导致重复。首次查询空词由UI转常用项，不发空搜索。

数据库所有检索、回填和关联查询均限制workspace与deletedAt；LIKE参数转义%/_/反斜杠。参考：[PostgreSQL模式匹配](https://www.postgresql.org/docs/17/functions-matching.html)。

当前独立路径落实知识检索。旧OpenAPI中的按多实体分组搜索是历史规划，不能据其声称该扩展接口已经实现；F23 UI对接这里的真实路径。
