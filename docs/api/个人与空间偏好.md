# 用户与空间偏好

GET/PATCH `/api/v1/users/me/preferences`读写本人theme，PATCH需CSRF与If-Match，旧版本412、缺版本428。主题服务器保存，本机按用户ID分开缓存，首屏内联应用最近缓存；缓存配额失败不阻断服务器保存，同步失败有重试反馈。
GET `/workspaces/{workspaceId}/preferences`返回有效业务总数、完成任务数、本人本空间上次提醒/业务导出时间和独立数据库备份状态。本机正式读取受限备份状态文件，返回ok/stale/failed/not_configured与无敏感路径摘要；超过24小时为stale。业务导出不替代数据库备份。
POST `/preferences/reminder`用事务锁按user+workspace领取提醒：总数>30或完成任务>500，最近显示不足24h不再显示，恰好24h可再次显示。不删除任何业务。
空间时区复用Owner PATCH `/workspaces/{workspaceId}`，IANA校验、If-Match、审计；前端必须勾选了解今日与统计边界变化后确认。已有DATE业务日期保持原值。
