# 回收站、审计与空间维护

Owner接口均位于`/api/v1/workspaces/{workspaceId}`。GET `/trash?type=project|task|entry|log|ledger&limit=30&cursor=...`限定空间及已删除对象，游标验证归属；返回保留截止时间。POST `/trash/{type}/{id}/restore`需If-Match，清除失效项目/知识/任务关联，不恢复父对象。DELETE `/trash/{type}/{id}`需If-Match、CSRF、Idempotency-Key及`{confirm:true}`；仅回收站对象可彻底删除，同key可重放。

硬删项目先置空子项目引用并递增子版本；硬删知识先解除台账和任务引用，再清修订/usage/标签；硬删任务清理关联。所有步骤与审计同事务。后台每小时处理30天到期的软删除记录，每类最多50条一批，审计标为trash.expired，恢复后对象不再符合条件。不会因为知识30天未使用或业务总数超阈值而自动删除有效数据。测试可用MAINTENANCE_WORKER_ENABLED=false关闭定时器。

POST `/maintenance/clear`需Owner、CSRF、If-Match、幂等key和`{confirmName,backupAcknowledged:true,password}`。必须重新验证本人密码及精确空间名，自动生成成功的业务快照后，事务内仅清当前空间业务、标签、关系、修订、计数和来源映射；账号、成员、偏好、空间与审计保留，空间version递增。密码不进入幂等请求hash或审计。旧导入计划由workspaceVersion及清空审计时间拒绝，不能在清空后意外复活旧数据；同清空key重放不再次清空新数据。

GET `/audit-events?action=...&limit=50&cursor=...`仅Owner，稳定时间/ID分页且绑定空间和筛选，仅返回操作摘要、对象ID和操作者ID，不返回密码/邀请token/整篇正文。团队页复用既有版本条件成员角色变更、邀请、撤销和移除接口；邀请token仅本次创建响应显示，不发送消息或写入普通快照。

页面位于设置下的“成员与邀请”“回收站与空间维护”“操作审计”。彻底删除和清空均有明确确认；清空取消不发送变更请求，结果未知必须复用原key。Native dialog支持键盘焦点范围及Escape取消，提交中禁止关闭。
