# 任务知识沉淀（F25）

POST /api/v1/workspaces/{workspaceId}/tasks/{taskId}/promote，Editor及以上；CSRF、If-Match及Idempotency-Key必需。body为{newEntry?:boolean}，默认false。返回201 data:{entryId,taskVersion,created,replayed}。

新建排错draft，预填任务、卡点和解决方案占位，关联同空间有效项目。CAS任务version与知识、关联、审计在同一事务内。默认已有沉淀直接返回；显式newEntry才另建。重复key重放原结果，旧version412、无版本428、无权403、跨空间或删除404。

GET任务详情增加entries:[{id,title}]，GET知识详情增加taskLinks:[{id,title}]，只返回当前空间未删除对象。前端增加/tasks/:taskId详情路由，今日卡和项目任务区均可沉淀，跳编辑后正文聚焦，反向可回访任务。
