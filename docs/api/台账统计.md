# AI台账统计

GET `/api/v1/workspaces/{workspaceId}/analytics/monthly?month=YYYY-MM`，month缺省为空间时区当前月。按DATE业务日归月，过滤软删除，以记录数为均分分母并四舍五入一位；返回场景count/minutes/savedMinutes/averageEffect、全月总数和可核验文本结论。并列依次按均分、样本数、场景标识稳定排序。空月scenes=[]，总计0，无效果结论。

GET `/analytics/weekly` 返回空间时区今天为锚点的八个自然周，含本周，周一为起点，升序。没有记录的周补0，当周只累计到今日。每周返回start/end/weekStart/count/minutes/savedMinutes，单位分钟。客户端不能传任意统计日期替换当前空间锚点。

两接口只读，Viewer可用，所有SQL限制workspaceId和deletedAt。聚合不经过图表反推数字；SQL分组与领域纯函数以同一手算样本交叉验收，跨年周与全零检查见FS027。
