# 知识列表正文边界（F41）

GET /api/v1/workspaces/:workspaceId/entries 的 entries 为详情字段集合去掉 body。保留bodyBytes、title、summary、type、status、tags、version和关联元数据；正文检索仍可匹配，但不会把正文随列表传回。详情 GET /entries/:entryId 才返回完整body，最大20480 UTF8字节。

前端EntryList类型为Omit<Entry,'body'>[]。真实HTTP检查验证20KB正文在列表中缺失body键、bodyBytes为20480，详情内容完整不变。分页和权限语义不变。
