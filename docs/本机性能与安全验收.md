## 冻结限制与安全

- 本机单API实例；连接池每实例最多10，获取连接5秒、空闲30秒；事务与业务日会话固定UTC。
- 普通请求15秒；导出快照120秒，导入提交事务15分钟；导出/导入各单worker循环，租约60秒、最多3次恢复尝试。
- 普通JSON128KiB，知识正文20480 UTF8字节，列表最多100；导入512MiB、25万实体/25万关系、深度20，下载保留24小时。
- 磁盘低于20%提醒、低于10%暂停高体积导入导出，普通读取可用。
- 生产默认登录10次/分钟、搜索60次/分钟；压测搜索设1000次/分钟，仅测试环境；会话空闲24小时、绝对7天，HttpOnly+SameSite=Lax、CSRF+Origin，回环HTTP不加Secure。
- API private/no-store、nosniff、DENY、no-referrer；正文安全渲染与空间权限用实际回归验证。
- 生产依赖audit当前0已知告警；源码密钥扫描未发现命中。不能以扫描替代权限/事务/XSS验证。
