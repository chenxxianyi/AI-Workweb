# 本机应用壳与私有只读副本

正式构建在登录后的应用壳注册Service Worker，构建时生成精确静态清单和内容版本号。共享CacheStorage只保存index.html、带hash脚本/样式及公开图标/manifest；认证、邀请、重置密码、下载和API不进入共享缓存，所有API响应均private,no-store。首次安装失败清理自己的不完整cache，更新保留当前及前一版本，不改其他命名空间。用户保存输入后点击更新；未保存保护由F37补齐。

近期业务副本在IndexedDB按userId+workspaceId+路径隔离：只允许项目/任务/知识列表或详情、日志列表、今日视图和台账列表，最多50个、每份≤1MiB、7天内可用；统计、搜索、团队和传输不回退到副本。网络或服务器错误时明确显示“离线只读副本”和保存时间，Workspace写入在客户端拒绝；未缓存内容显示不可用，不用旧数据伪造成功。恢复连接需要验证当前身份并重新加载。

冷启动只投影最近24小时已验证的用户ID、显示名、空间名称和时区，不缓存auth/me原响应、邮箱、密码、cookie、会话或邀请token；冷启动投影一律Viewer，只读并待联网核验。没有有效本机身份时显示连接不可用说明。401不允许身份回退，403/404及空间移除清理相关副本，退出或换账号清理本人私有资料。迟到请求通过用户身份及有效scope守卫，不能重新填入另一账号缓存。

离线退出立即清理本机资料，保存不含凭证的待退出标记；联网后先完成服务器退出，之后才能重新登录。服务器会话无法在断网时立即吊销，界面明确显示待完成状态。标记采用本地存储和独立布尔cookie，不读取或复制HttpOnly会话cookie。

设置中的“本机离线资料”显示实际应用壳状态、共享缓存异常响应数、当前空间副本数量，并可清理只读副本。这是浏览器业务副本，不是数据库备份；本阶段没有自动离线写入，指定队列在F36实现。

实现参考：[应用壳导航处理](https://web.dev/articles/handling-navigation-requests?hl=en)、[Vite预览代理](https://vite.dev/config/preview-options)。实际边界以本仓库白名单和FS035证据为准。
