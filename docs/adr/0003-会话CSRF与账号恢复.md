# ADR-0003 · 会话 Cookie、CSRF 与账号恢复

- 状态：已接受（F03）
- 日期：2026-11-03
- 关联：R01、R02、R26；方案第 7 节

## 背景

私有部署、无邮件服务、需要可吊销的登录态。浏览器不得保存长期访问令牌；修改类请求必须防止 CSRF；恢复流程不能依赖邮件，也不能内置通用默认密码。

## 决策

1. **服务器会话 + 不透明 Cookie**
   - Cookie 名 `sfs_session`，值为 32 字节随机数的 base64url；`HttpOnly`、`SameSite=Lax`、`Path=/`；HTTPS 下加 `Secure`；开发（http://127.0.0.1）不加 `Secure` 并在启动日志明确提示。
   - 数据库 `sessions` 只存 `token_hash`（SHA-256）与 `csrf_token_hash`，不存原始 token。
   - 空闲 24 小时、绝对 7 天；登录成功**轮换**会话 id；改密、移除成员、显式退出时吊销相关会话。
2. **CSRF**
   - 双提交：`GET /auth/csrf` 返回一次性 CSRF token（同时存 `csrf_token_hash`），写请求必须带 `X-CSRF-Token`。
   - 同时校验 `Origin`／`Referer` 与配置的允许来源；`SameSite` 不作为唯一防线。
   - 校验失败返回 403 `CSRF_INVALID`，不触发业务逻辑。
3. **密码**
   - Argon2id（`argon2` 0.45.2），参数在部署机器上校准并在配置中固定；哈希不出 API、不进日志。
   - 强度：≥12 字符；不设“安全问题”。登录失败统一文案 401 `AUTH_INVALID_CREDENTIALS`；按 IP + 账号限流（`@nestjs/throttler`）。
4. **恢复**
   - 无邮件：由运维执行服务器命令 `recovery:issue --email <x>` 签发一次性令牌（30 分钟、只存哈希、有审计），Owner 手工传递；`POST /auth/recovery/complete` 消费令牌并设新密码，同时吊销该用户全部会话。
   - 邀请：`POST /workspaces/{id}/invitations` 生成一次性令牌（默认 48 小时、只存哈希），返回一次明文链接；列表不再暴露 token；已有账号只建立成员关系，不重设密码。
5. **跨源**
   - 默认同源部署，不启用任意 CORS；开发期由 Vite 代理 `/api` 到后端，浏览器始终同源。

## 后果

- 会话与 CSRF 都落库，登录态查询有一次数据库往返；用 `sessions(token_hash)` 唯一索引承担。
- 前端需在应用启动时先取 CSRF token，并随写请求携带；离线写请求排队时需保存当时的 CSRF token 并在恢复后刷新（过期的 CSRF 失败会重试一次）。
- 服务器时钟偏移会影响绝对过期：部署时启用 NTP，文档写入运维手册（F51）。

## 替代方案

| 方案 | 未采用原因 |
|---|---|
| JWT 访问令牌 | 无法即时吊销；浏览器需保存长期令牌，与方案第 7 节冲突 |
| 仅 SameSite=Lax | 不能覆盖同站子域与旧浏览器；不满足 R26 |
| 内置默认管理员密码 | 违反“无通用默认密码”；F08 用 bootstrap 命令交互式创建 |

## 落地记录（F09，2026-11-03）

| 决策点 | 实现 |
|---|---|
| Cookie | 会话 `sfs_session`（HttpOnly、SameSite=Lax、Secure 由 `COOKIE_SECURE` 控制）；CSRF `sfs_csrf` 可被 JS 读取 |
| 令牌存储 | 会话与 CSRF 均只存 SHA-256（`sessions.token_hash` / `csrf_token_hash`） |
| 过期 | 空闲 `SESSION_IDLE_MINUTES`（默认 1440）／绝对 `SESSION_ABSOLUTE_DAYS`（默认 7）；滑动续期 60 秒节流 |
| 登录轮换 | 每次登录新建会话并轮换 CSRF；多设备各自独立会话 |
| CSRF | 已登录走会话绑定哈希；未登录（登录）走双提交；同时校验 Origin/Referer 与 `PUBLIC_ORIGIN` |
| 恢复 | `POST /auth/recovery/complete` 用 `@CsrfExempt()`（持有型令牌），成功后吊销全部会话 |
| 登录锁定 | 15 分钟 5 次失败 → 429；成功清零（进程内；多实例限制已在 FS008 记录） |
| 重启存活 | 会话在数据库，重启后同一 Cookie 仍有效（F09 的 `test:session` 含“关闭应用再起”用例） |
