# ADR-0007 · 前端样式令牌、图标与组件自建

- 状态：已接受（F03）
- 日期：2026-11-03
- 关联：R25、R11、R21；F02 设计决策 D-01～D-07

## 背景

私有部署、离线优先、禁止公共 CDN。引入 UI 组件库会带来许可、体积与主题覆盖成本；但完全无约束的样式会让 375px、深色模式与对比度难以一致。

## 决策

1. **不引入 UI 组件库、图标库、图表库、CSS 框架**。样式用 CSS 变量 + CSS Modules（按组件作用域），全局只保留令牌与 reset。
2. **令牌**（`apps/web/src/styles/tokens.css`，F03 冻结初版）：

   | 角色 | 浅色 | 深色 |
   |---|---|---|
   | `--bg` | `#f8fafc` | `#0b1220` |
   | `--surface` | `#ffffff` | `#121b2a` |
   | `--text` | `#0f172a` | `#e2e8f0` |
   | `--muted` | `#475569` | `#94a3b8` |
   | `--border` | `#e2e8f0` | `#243044` |
   | `--primary` | `#0f766e` | `#2dd4bf` |
   | `--primary-soft` | `#ccfbf1` | `#134e4a` |
   | `--danger` | `#b91c1c` | `#f87171` |
   | `--warn` | `#b45309` | `#fbbf24` |
   | `--success` | `#047857` | `#34d399` |

   - 间距 4 的倍数（4／8／12／16／24／32）；圆角 8／12；阴影两级；字体：系统栈 `system-ui, "Segoe UI", "Microsoft YaHei", "Noto Sans SC"`，等宽 `ui-monospace, "Cascadia Code", Consolas`。
   - 正文最小对比度 4.5:1，禁用态 ≥3:1；颜色不作为唯一指示（紧急度同时有文字／图标）。
3. **图标**：内联 SVG（24×24 viewBox，`currentColor`），集中在 `apps/web/src/components/icon.tsx`；不引图标字体、不引 CDN。
4. **图表**：两张 SVG 自绘（按场景条形、近八周折线），纯函数生成坐标，空数据显示文字而非 0 高度误导线。
5. **主题**：`data-theme="light|dark"` 挂在 `<html>`；偏好来自服务器（`/me/preferences`）并本地缓存；首屏前由内联脚本应用，避免闪白。
6. **响应式**：`<768px` 单列 + 底部标签栏；`768–1023px` 两列 + 折叠导航；`≥1024px` 左侧 216px 导航 + 主区最大 1180px。

## 后果

- 组件需自行实现可访问性（焦点环、`aria-*`、键盘操作），由 F07 建立基础组件并在 F38／F42 回归。
- 无第三方组件升级负担，但样式一致性依赖令牌纪律：禁止硬编码颜色，CI 增加简单检查（F07 起）。

## 替代方案

| 方案 | 未采用原因 |
|---|---|
| shadcn/ui + Tailwind | 需要构建期依赖与主题体系；离线部署虽可行但增加维护面 |
| Ant Design | 体积大、主题覆盖成本高，与本项目视觉密度不符 |
| 直接写内联样式 | 无法保证 375px 与深色模式一致性 |
