# ADR-0009 本机部署与本机验收范围

- 日期：2026-11-03
- 决策依据：项目所有者明确要求“部署就在本地部署即可，不用docker”，并确认“按本机范围验收，Safari和异机灾备列为后续扩展”。
- 本决策覆盖原方案相冲突的生产环境要求，其余业务、权限、事务、幂等与数据完整性规则继续有效。

## 当前交付

Windows本机Node.js + PostgreSQL原生运行，正式前端构建由本机应用服务同源提供。默认仅监听127.0.0.1，不默认开放局域网或公网。提供可重复的安装检查、正式构建、启动、停止、状态、备份恢复、回退和本机巡检入口。

F43由镜像／Compose改为原生正式运行包；F44提供本机验证和发布流水线；F45是与开发库隔离的本机预发布；F46本机备份与恢复；F47本机版本回退；F49本机健康巡检与日志；F50本机正式部署。任务编号和存档点不变，每一步仍单独实测归档。

## 验收范围

- 在本机可用Chrome／Edge或对应可用Chromium环境完成自动化及可实际执行的浏览器验证，报告准确记录浏览器名称和版本。
- Safari实机、异机灾备、公网域名、外部CI平台和外部告警通道不作为本轮本机交付门槛。
- 不使用Docker，不要求先安装容器环境。
- 仍测试375px、键盘、表单、权限、双会话冲突、离线与恢复。
- 备份恢复在隔离库演练；本机备份不声称能承受整机／整盘损坏，异机副本列入后续扩展。
- 用户已授权按任务顺序实现、自测并验收；技术结果由执行者记录，不伪造业务签字或未实际使用的用户反馈。

## 历史与追踪

原始方案保留；需求矩阵、任务文档、进度、README及最终报告引用本ADR。未验证的外部环境不得写成通过，也不再用已移出本轮范围的条件阻止本机交付。
