# ADR-0010 关联查询与本机运行限制

- 日期：2026-11-04；关联任务F41。
- 保持Prisma7.10.1/pg8.23.1固定版本，启用官方relationJoins预览配置；没有数据库结构变更，重新生成客户端即可。24个真实DB套件回归后接受；回退配置时重生成客户端并重测。
- 按页面拆分前端，知识列表响应只含摘要/字节数等元数据，详情才返回body。API契约相应调整；后台查询仍按范围分页，不把全库正文发到首页。
- 每实例连接池10，连接超时5秒、空闲30秒；本机单实例，传输worker各单循环。大导入单事务上限15分钟，后台状态查询保持短请求。
- 大作业中的Prisma内部chunk查询仍可能触发pg8弃用告警，保留原始栈与真实数据验收；固定版本下不是事务失败，不以隐藏日志消除。升级pg9前必须复核驱动策略。
- 磁盘20%提醒、10%暂停高体积作业；阈值按真实statfs计算。其余实测指标、测试规模及适用硬件见F41性能报告，未在2vCPU/4GiB受限机器验证，不作该规格保证。

来源：[Prisma 7关联查询策略](https://www.prisma.io/docs/orm/v7/prisma-client/queries/relation-queries)。
