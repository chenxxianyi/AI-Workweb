# ADR-0006 · 离线缓存与同步队列边界

- 状态：已接受（F03）
- 日期：2026-11-03
- 关联：R24、R23、R26；方案第 11 节

## 背景

私有部署常在内网／弱网环境使用。完整离线 CRUD 会带来复杂的冲突合并与权限漂移问题；但不提供任何离线能力会让移动端体验明显变差。

## 决策

1. **Service Worker 只缓存版本化静态资源**（`index.html`、JS/CSS、图标、manifest），不缓存业务 API 响应；认证、导出、邀请、下载 URL 永不进入通用缓存。
2. **业务只读缓存**用 IndexedDB，按 `userId + workspaceId` 分区；退出登录或切换账号时清理已同步分区；未同步队列必须先提示导出或明确保留在原账号分区。
3. **允许离线写入的三类操作**（其余一律要求在线并在 UI 禁用）：
   - 新建开发日志；
   - 新建知识草稿；
   - 修改已有任务的状态（todo／doing／done）。
4. **队列语义**
   - 每条队列项存 `idempotencyKey`、`scope`、`payload`、`baseVersion`、`createdAt`、`attempts`、`lastError`。
   - 恢复联网后按创建顺序串行提交；成功 → 标记已同步并从队列移除；412 → 进入冲突面板；403／410 → 停止重试并提示保留本地副本。
   - 队列超过 7 天的条目不再自动重发（与 ADR-0004 幂等保留期一致）。
5. **状态显示三值**：`已保存`（服务器事务提交成功）／`待同步`（本地队列）／`保存失败`（含结果未知，附 requestId 与重试）。禁止把“待同步”显示为“已保存”。
6. **在线数据**：活跃页每 30 秒轮询相关资源，页面隐藏时暂停并退避；切回前台立即刷新一次；不做 WebSocket 实时协同。

## 后果

- 离线可写范围有限，需在 UI 明确提示“离线仅支持日志／草稿／任务状态”。
- 权限被远端撤销时，离线设备上的缓存内容无法即时擦除；重新联网必须拒绝访问并清理该空间缓存（方案第 11 节）。
- 冲突处理复用 ADR-0004 的 412 流程，队列不实现自动合并。

## 替代方案

| 方案 | 未采用原因 |
|---|---|
| 完整离线 CRUD + CRDT | 实现与验证成本远超本期范围（方案第 3.2 节） |
| 只做只读缓存 | 移动端无法记录临时想法，失去 R24 的主要价值 |
| 后台同步（Background Sync） | Safari 支持不稳定，本期用前台可见队列 |
