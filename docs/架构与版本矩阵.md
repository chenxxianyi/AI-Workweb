## 5. 版本偏差与风险（不伪装为已满足）

| 偏差 | 影响 | 处置 |
|---|---|---|
| Node 22.23.4 < 方案建议的 26 LTS | 个别 26 新 API 不可用；长期支持窗口更短 | ADR-0002：以 `engines` 限制在 22；不使用 26 独有 API；F44 前复核并评估升级 |
| TypeScript 5.9.3 < 最新 7.0.2 | 无 7.x 原生编译性能收益 | ADR-0002：NestJS 装饰器元数据与 Prisma 类型生成在 5.9 线更稳；升级单独立项 |
| 本机无 Docker | F43～F47 无法执行 | F43 前由项目所有者提供 Docker Desktop 或等价 Linux 环境；否则相关阶段标“阻塞” |
| Prisma 7 使用 driver adapter + 新 client 生成器 | 与 6.x 的 `PrismaClient` 初始化方式不同 | F05 用 `@prisma/adapter-pg` + `prisma-client` 生成器落地，并在 FS005 记录实际生成物 |
| argon2 为原生模块 | Windows 需预编译二进制或 VS Build Tools | F04/F08 验证安装；失败则退回 Node 内置 `crypto.scrypt`（需另立 ADR） |
| 无邮件服务 | 邀请／恢复不能发信 | 邀请链接手工传递；恢复用服务器 CLI 签发一次性令牌（ADR-0003） |
