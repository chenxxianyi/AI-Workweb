### 会话失效（独立验证）

1. 登录后停留在今日页；
2. 直接吊销该用户全部会话（`update sessions set revoked_at = now()`）；
3. 点击「设置」（SPA 内导航，不刷新）→ 设置页请求返回 401；
4. 结果：出现对话框「登录已过期 … 当前页面的输入不会丢失，重新登录后可继续」，点击「重新登录」→ `/login?next=%2Fsettings`。

> 说明：直接刷新页面（整页加载）时会话失效会被当作“未登录”并重定向登录页，不弹过期框——这是有意设计（避免登录页上方浮出过期提示）。

## 6. 权限展示与边界

| 项 | 实现 |
|---|---|

## 7. 缺陷与修复

| 编号 | 现象 | 根因 | 修复 |
|---|---|---|---|
| D-F11-01 | 未登录打开 `/settings` 时弹出“登录已过期” | 401 回调不看登录态，启动探测的 401 也触发 | 用 `statusRef` 仅对 `authenticated` 状态的 401 弹框；启动探测与登录页 401 视为未登录 |
| D-F11-02 | E2E 首次运行点击被对话框拦截 | 同一原因 + 开发服务器 HMR 保留了旧状态 | 修 D-F11-01 后重启 dev server 复测通过 |
| D-F11-03 | 空间切换断言“未改变” | 上一次运行已把第二个空间写入 `localStorage`，测试选中的正是当前空间 | 测试改为选择“与当前不同”的空间，验证值确实变化 |
| D-F11-04 | 桌面视口截图超时 | 浏览器窗口被最小化（`outerWidth=160`），非全页截图无法合成 | 改用 `fullPage: true` 截图成功；并记录窗口可见性限制 |
| D-F11-05 | 单元测试缺少 DOM matcher / 组件未卸载 | 未引入 `jest-dom`，且 vitest 未开 globals 导致自动 cleanup 不生效 | 新增 `vitest.setup.ts` 调用 `cleanup()`；断言改为原生 DOM 属性 |
| D-F11-06 | `context.clearCookies` 被浏览器拒绝 | Tabbit 限制该 CDP 命令 | 改为走正常“退出”流程准备状态；失效会话改用数据库吊销 + 页内导航验证 |
