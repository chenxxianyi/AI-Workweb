## 3. 请求层与错误分类（单元测试 14/14）

`pnpm --filter @aiwb/web test` → **14 passed**：

- 信封解包只返回 `data`；GET 使用 `credentials: same-origin`
- 422 → `ApiError{kind:'http', status:422, code:'VALIDATION_FAILED', fieldErrors, requestId}`
- 412 → `isConflict=true` 且 `currentVersion` 透传；`If-Match: "8"` 正确拼接
- 401 → `isUnauthenticated=true`
- 无信封的 500 → 稳定错误（不含内部细节）
- 网络失败 → `kind='network'`，`isUnknownResult=true`
- 超时 → `kind='timeout'`，`isUnknownResult=true`
- 调用方用自身 signal 取消 → 原样抛出 `AbortError`（上层忽略，不当作失败）
- 写请求带 `X-CSRF-Token` 与 `Idempotency-Key`
- `EpochGuard`：新作用域使旧令牌失效；旧作用域的慢响应返回 `{stale:true}` 且不返回数据；同作用域结果被采用
- 主题解析：`system` 跟随系统，显式值覆盖

## 6. F07-02 边界（切换空间与旧响应）

| 检查 | 实际 |
|---|---|
| 切换空间取消旧请求 | `switchTo()` 先 `begin()` 递增 epoch，再 `cancelQueries()` 与 `queryClient.clear()`，然后切换 id |
| 延迟返回的旧响应不能覆盖新页面 | 查询键以 `workspaceId` 开头（旧键被清除）+ `EpochGuard/runScoped` 丢弃过期结果（单测覆盖） |
| 浏览器证据 | 导航/切换时在途请求被标记 `ERR_ABORTED` |
