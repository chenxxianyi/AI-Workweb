## 3. 关键设计取舍

| 取舍 | 原因 |
|---|---|
| 幂等记录在**同一事务**里占位并写回响应 | 业务变更与“已执行”标记原子提交；进程中断后不会出现“数据写了但没记幂等” |
| 同键异体直接 409，不做内容合并 | 静默执行不同请求会掩盖客户端 bug（ADR-0004） |
| `shiftDays` 由服务端按业务日计算 | 客户端时钟/时区不可信；跨月跨年与闰年统一在 `@aiwb/domain` 覆盖 |
| 顺延先 dryRun 再确认，且校验受影响行数 | 避免“部分更新”与误改更早逾期/已完成任务 |
| `doneAt` 与 `status` 由服务端成对维护 | 数据库 CHECK 兜底，客户端不能只改其一 |
