## 6. 权限与边界

| 项 | 实现 |
|---|---|
| 只读角色 | `can('business.write')` 为 false 时不显示新建/编辑/归档/删除入口，并提示“只读角色，不能创建或编辑项目” |
| 界面不是边界 | 隐藏按钮只是提示；服务端 `WorkspaceGuard` + `business.write` 校验（F10/F12 有 403 用例） |
| 条件写 | 编辑/归档/删除均带 `If-Match`；412 时显示服务端文案（“该项目已被其他设备修改”），不静默覆盖 |
| 归档语义 | 归档只把项目移出进行中；详情明确“任务、知识与台账仍然保留”，不做级联删除 |
| 删除 | 软删除 + 二次确认；文案说明进入回收站、恢复在 F34 |
