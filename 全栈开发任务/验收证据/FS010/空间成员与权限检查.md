`pnpm --filter @aiwb/api test:workspace`：

| 分组 | 用例（全部 PASS） |

| 角色权限 | Editor 改空间 → 403；Editor 邀请 → 403；Viewer 读所属空间 200；**Viewer 访问未加入空间 → 404**；Viewer 写 → 403；Viewer 移除他人 → 403 |
| 最后 Owner | 降级最后 Owner → 409 `LAST_OWNER_PROTECTED`；移除最后 Owner → 409 |
| 移除成员 | 移除 Editor 成功并吊销 ≥1 个会话；被移除者下次请求 → 401 |
| 空间隔离 | 另一个空间 + Viewer 仅能访问自己加入的空间（跨空间 404） |

## 3. 关键设计取舍

| 取舍 | 原因 |
|---|---|
| 非成员一律 404，成员但越权才 403 | 与设计文档一致，避免用状态码探测其他空间是否存在 |
| 成员集合 `SELECT … FOR UPDATE` | 并发降级两个 Owner 时，第二个事务会看到最新 owner 数，防止出现“零 Owner” |
| 移除成员同时吊销会话 | 方案第 7 节“移除成员及时吊销”；F10 断言被移除者立即 401 |
| 邀请不能直接给 Owner | 避免误操作导致权限失配；所有权转移应是显式流程（后续任务） |
| 接受邀请豁免 CSRF | 凭据是一次性邀请令牌，邀请人可能尚未登录；已在 C-16 记录 |
| 允许成员移除自己 | 退出空间的自然路径；仍需保护最后 Owner |
